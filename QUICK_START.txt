🚀 ৩ মিনিটে শুরু করো:

1️⃣  Telegram বট তৈরি
   @BotFather → /newbot → TOKEN নাও

2️⃣  Chat ID নাও
   getUpdates API থেকে → id কপি করো

3️⃣  সেটআপ করো
   bash setup.sh
   (TOKEN এবং Chat ID দাও)

4️⃣  সার্ভার চালু করো
   bash start.sh

5️⃣  লিংক শেয়ার করো
   http://localhost:3333
